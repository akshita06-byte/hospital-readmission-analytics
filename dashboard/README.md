# Dashboard Screenshots

Place your exported Tableau dashboard screenshot here as:
`dashboard_screenshot.png`

### How to export from Tableau Public:
1. In Tableau Public Desktop (or in your web browser viewing your published dashboard):
2. Click **File** -> **Export Image...** (or click the **Download** button -> **Image** on the web page).
3. Save the image in this directory with the filename `dashboard_screenshot.png`.
4. It will automatically render in the main `README.md`!
